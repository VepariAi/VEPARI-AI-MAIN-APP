# 2. CRITICAL ARCHITECTURAL DECISION

Vepari AI is fundamentally **local-first/offline-first**.

The authoritative business data model is designed around the user's device.

### Primary business data

**Encrypted local SQLite**

### Financial source of truth

**Custom accounting engine operating over the local business database**

### AI personalization

**On-device Memory Engine / AI context**

### Cloud

**Minimal/optional**

### Cloud learning

Only through explicitly permitted/consented signals.

### Default rule

**Raw business data must not automatically be uploaded to the cloud merely because the application is being used.**

This distinction is critical to the Vepari AI architecture.

# 153. FINAL TECHNICAL DEFINITION

**Vepari AI is a local-first, offline-first, AI-native Business Operating System built primarily for Android using React Native + Expo + TypeScript, with encrypted SQLite as its primary local business database and a custom accounting engine as the financial source of truth.**

Its intelligence layer is built around an **on-device Memory Engine**, while optional cloud infrastructure provides controlled synchronization, integrations, services and consent-based learning capabilities rather than automatically becoming the repository for raw business data.

The platform supports the full:

**Micro → Small → Medium → Enterprise**

business spectrum, with deeper specialization for Micro businesses and progressive complexity for larger organizations.

Its AI layer is provider-agnostic and supports **Sarvam AI** for the Indian-language/voice strategy.

Its core interaction model is:

> **Business Data → Memory → Intelligence → Insight → Action → Business Data**

Its core security model is:

> **Secure Device → Authentication → Authorization → Encryption → Controlled Cloud → Audit**

Its core reliability model is:

> **Local First → Offline → Queue → Sync → Reconcile**

Its development model is:

> **Shared GitHub Repository → Independent Development Devices → Committed Source of Truth**

And its future expansion model is:

> **Android → iOS → Connection Portfolio → Larger MSME/Enterprise ecosystem**
