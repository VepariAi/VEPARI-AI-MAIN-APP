# docs/development

Developer guides and setup documentation for Vepari AI.

**Expected contents (populated during Phase 9 and onward):**
- Local development environment setup
- Environment variable reference (names only — never values in Git)
- Branch naming and Git workflow guide
- Code style and linting configuration
- React Native + Expo setup walkthrough
- Android emulator / physical device setup
- Multi-machine development guide (see `Project Instructions.txt §13`)
- Contribution guidelines

**Security constraint:** Environment variable values, API keys, and secrets must never appear in this directory or anywhere in Git. Document variable names and their purpose; store values in `.env` files (gitignored) or a secrets manager.

**Status:** Directory established. Population begins at Phase 9 (React Native foundation).
