P47 — Spacing, Corner Radius and Elevation

Prompt 47 · Phase 5 · Depends on Prompt 46 — spacing scale, 5 radius levels, 6 elevation layers

Spacing Scale

Base unit: 4dp. All spacing tokens are multiples of 4. Screens.png proportions verified: card padding is ~16dp, list-item vertical padding is ~12dp, icon-to-label gap is ~6dp, FAB margin is ~20dp, bottom-nav height is 56dp (Voice tab elevated to 72dp footprint). Smallest interactive target: 44dp min touch area per iOS/Material guidance.

Corner Radius Scale

Derived from Screens.png: small controls (buttons, chips, badges) have tight radii ~8dp; cards have ~12dp; sheets and drawers have ~20dp top corners only; dialogs have ~16dp; AI Core and AI surfaces use a larger ~24dp radius for a softer, premium feel (UI-UX §12).
TokenValueDemoComponents
--radius-xs 4dp Badge, pill label, table cell highlight, code token background
--radius-sm 8dp Button (all sizes), chip, filter tab, text field, search bar, icon button
--radius-md 12dp Card, MetricCard, ListItem card, document preview, alert banner, toast
--radius-lg 16dp Dialog, modal container, bottom sheet inner handle area, large CTA card
--radius-xl 20dp Bottom sheet top corners, drawer top corners, full-screen modal top corners
--radius-ai 24dp AI Briefing card, AI Insight card, AI chat bubble (own side), AI surface containers
--radius-full 9999dp Avatar, circular icon button, Voice FAB, progress indicator track, toggle thumb
