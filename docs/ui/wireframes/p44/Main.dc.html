Component States
Reusable — referenced by all screens (P33–P43)
6 state components
📭
Empty
No data yet. Encourage first action with icon + headline + CTA button.
Used in: Transactions, Customers, Inventory, Alerts
⚠
Error
Something went wrong. Show message + retry button. Never blank screen.
Used in: Reports, Sync, API calls
⏳
Loading
Skeleton shimmer rows matching the expected content layout below.
Used in: All lists, charts, detail screens
📶
Offline
No internet. Show cached data with staleness label. Queue writes.
Used in: Home, Transactions, Sync status
⚡
Conflict
Two edits conflict. Show both versions, let user choose or merge.
Used in: Inventory, Customer edit, multi-device sync
🔒
Permission Denied
Feature not available for this role or plan. Show upgrade path.
Used in: Reports, Settings, Staff management
