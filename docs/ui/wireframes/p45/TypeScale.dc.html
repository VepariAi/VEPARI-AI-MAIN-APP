Line-height Rationale

English
1.2–1.45 × font-size. Tighter at display sizes, looser at body. Standard Latin ascender/descender geometry.
Devanagari
+0.2 added to every English ratio. Matra (vowel mark) extends above the headline; without extra leading, matras clip on adjacent lines.
Rule
Apply line-height via CSS custom property per locale: [lang="hi"] { --lh-body: 1.65; } [lang="en"] { --lh-body: 1.45; }
