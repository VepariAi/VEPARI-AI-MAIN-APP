Accessibility Specification — Contrast, Touch Targets, Dynamic Type

Prompt 55 · Phase 5 · Accessibility Spec · 860 px reference document
Depends on: Prompt 18 (accessible design principles), Prompt 46 (color tokens). Checks: every token pair from P46 against WCAG 2.1 AA.
WCAG 2.1 AA thresholds: normal text ≥ 4.5:1 (text <18pt regular / <14pt bold); large text ≥ 3.0:1 (text ≥18pt / ≥14pt bold); UI components ≥ 3.0:1. All contrast ratios were calculated programmatically against the confirmed P46 brand hex values. Relative luminance per WCAG 2.1 §1.4.3 using the standard IEC 61966-2-1 gamma curve.
1 · Complete Contrast Ratio Audit — All P46 Token Pairs
Critical finding — Heritage Gold (#C8A96B): This color FAILS WCAG AA as text on every light background (2.10:1 on Ivory White, 1.85:1 on Warm Beige, 2.25:1 on White). Heritage Gold must NEVER be used as body/label/heading text on light backgrounds. It passes only on Deep Brown (#3B2F2A) at 5.75:1. Use Heritage Gold as a decorative accent — borders, active dots, icon fills — not as text on light surfaces.

3 · Minimum Touch Target Sizes

4 · Dynamic Type Scaling
iOS Dynamic Type maps user accessibility text-size settings to a multiplier. React Native's allowFontScaling prop (default true) applies this. Vepari AI adopts a clamp strategy: scale up to a capped maximum rather than letting text scale unboundedly (which breaks fixed-width layouts). Minimum type size is never reduced below 12sp. Indic scripts need additional line-height headroom at all sizes — see the Indic multipliers.

Implementation pattern: Use allowFontScaling={true} (default) on all Text nodes. Cap via maxFontSizeMultiplier={1.4} on navigation labels, badge text, and dense table cells. Never set allowFontScaling={false} unless the element is a decorative graphic (icon, chart axis label). Flex containers use minHeight instead of fixed height on rows containing text.
5 · Quick Reference Rules
  • Heritage Gold is NOT a text color on light backgrounds — use as dot, border, active indicator, decorative stripe only. Text on Deep Brown: 5.75:1 ✓ only valid text use.
  • Error text must land on white (#FFFFFF) — Terracotta on Ivory White (#FAF7F2) is 4.33:1, marginal. Error containers (FDECEA background) should have Deep Brown text for body copy, Terracotta for the icon and heading only.
  • Text Tertiary (#9A8A82) is decorative only — placeholder text, skeleton labels, very secondary meta info at sizes ≥18pt. Never for key data, values, actions, or reading-critical copy.
  • Text Secondary (#7A6A60) is safe on Ivory White (#FAF7F2) and White (#FFFFFF) — not on Warm Beige (#F2E8D6) at normal text sizes (4.26:1 fails).
  • All interactive touch targets ≥ 44 dp — use hitSlop when visual element is smaller. Never use pointerEvents: 'none' on elements the user needs to interact with.
  • No fixed height on text containers in Indic locales — Telugu diacritics extend 25% above line, requiring extra clearance at all scale steps. Use minHeight.
  • Badge text at 9sp is exempt from dynamic type scaling — the badge container grows instead. Cap nav label scaling at 1.18× (13sp max) so the label never wraps.
  • Icons are UI components, not text — they need 3.0:1 against their background (not 4.5:1). All stroke icons on their confirmed backgrounds pass at ≥3.0:1.
