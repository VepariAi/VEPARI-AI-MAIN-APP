Physics and motion states (from Prompt 16):

Idle: No animation. Core gradient static. Outer ring border opacity pulses gently 0.15→0.27→0.15 at 4s ease-in-out. System is ready but not engaged.

Listening (user speaking / mic active): Inner core scales 1.0→1.06→1.0 at 1.2s ease-in-out infinite. Outer glow ring shadow blur 16→28→16dp in sync. Mid ring static. Diamond mark brightens (opacity 1.0 always during listening).

Processing (AI thinking): Mid ring rotates 360° at 20s linear infinite. Outer ring rotates −360° at 30s linear infinite (counter-rotation creates interlocking feel). Inner core gradient animates: position shifts 0°→180° at 3s ease-in-out alternate. Subtle shimmer on diamond.

Speaking (AI audio output): Inner core scale oscillates with audio amplitude (0.95→1.08 mapped to RMS, capped at 1.1). Glow shadow blur follows amplitude (12→32dp). Mid ring rotation slows to 60s. Outer ring pulses at 0.8s matching speech rhythm.

Error: All rotations stop. Inner core gradient transitions to --color-error → #5c1a14 over 300ms. Diamond mark hidden; error-triangle icon appears 14dp white. Shake animation: translateX(0→−4→4→−4→4→0dp) 400ms once. Outer glow uses rgba(160,49,42,.30).

Offline: All color desaturates to grayscale. All animations pause. Outer ring opacity 0.30. Diamond replaced by wifi-off icon.

Success (brief): Inner core flashes --color-success → returns to default gradient over 600ms. Diamond brightens, scale 1→1.15→1.0 over 300ms. No ring rotation change.

Touch target: 80dp minimum (full outer ring footprint). The 56dp Voice tab FAB button in the nav bar is a smaller variant of this motif — inner core only (40dp), no visible rings, same gradient and diamond mark. It uses Floating elevation (--elevation-3) and gains the glow ring on active listening.
