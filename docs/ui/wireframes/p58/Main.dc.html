Implementation note: The marketing image uses a 3-column layout with a massive central AI Core ring. Key insight for mobile adaptation: The marketing image is a 2D infographic, not a mobile screen. For the React Native AI OS Home screen (P61), the 3-column layout cannot be used at 390dp width. The adaptation strategy is: AI Core ring as full-width hero (~260dp diameter), engine cards in a 2×N grid below, bottom BI panel as a collapsible card, voice bar replacing the bottom navigation.
