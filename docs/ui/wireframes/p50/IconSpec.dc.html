P50 — Icon Set Specification

Prompt 50 · Phase 5 · Depends on Prompt 3 — engine icon mapping, nav icons, module icons, line weight, corner treatment, label-pairing rule per UI-UX §194
Icon source (Prompt 3 decision): The app uses a custom icon set built on a 24dp × 24dp grid, 2dp stroke weight, rounded line caps and joins (cap: round, join: round), minimum interior corner radius 2dp. Icons are delivered as SVG — rendered as React Native SVG components in the app. The 10 AI Engine icons (Voice Engine, Finance Engine, Customer Engine, Inventory Engine, Intelligence Engine, Memory Engine, Vision Engine, Growth Engine, Market Engine, Automation Engine) exist as pre-confirmed brand assets (PNG files in the repo). These are pixel-perfect references — the SVG versions must match them exactly in silhouette.

Construction Rules

Grid
24 × 24dp artboard. Safe area: 20 × 20dp (2dp bleed each side). Key line grid: circle 20dp, square 20dp, rounded-rect 18×20dp, wide 20×16dp.
Stroke weight
2dp uniform. No variation within one icon (no hairlines). Exception: AI engine icons use 1.5dp for inner detail elements to preserve legibility at 24dp.
Line cap
Round (SVG: stroke-linecap="round")
Line join
Round (SVG: stroke-linejoin="round")
Corner radius
Rectangular shapes: 2dp interior radius. Organic/circular shapes follow natural curve. Never sharp (0dp) corners on any filled shape.
Fill style
Outline-only (stroke, no fill) for all standard UI icons. Filled variant (stroke + matching fill) exists for active/selected states only (e.g. active nav tab). Engine icons use a dual-layer approach: colored outer shape filled, inner motif stroked white.
Pixel snap
All anchor points on 0.5dp or whole-dp positions. No sub-pixel paths. Optical adjustments allowed: a circle may be 19.5dp if it looks visually equivalent to a 20dp square.
Export
SVG with viewBox="0 0 24 24". currentColor for stroke/fill — color injected at render time via CSS or prop. No hardcoded color values inside SVG source.

Label-Pairing Rule (UI-UX §194)

Icons NEVER stand alone where ambiguous. Rule: if removing the label would leave a reasonable user unsure of the icon's action or meaning, the label is mandatory. Exceptions where icons may stand alone: universally understood glyphs (× close, ✓ confirm, ‹ back, ≡ hamburger menu, magnifier search) AND there is adjacent context that makes the action obvious. Navigation icons always paired with labels (tab bar + labels per P36 NavSpec). Engine card icons paired with engine name in all Home screen layouts. Badge-only icons (status dot, notification dot) require tooltip on long-press.

AI Engine Icons — 10 Confirmed Assets

These 10 icons are confirmed brand assets (PNG source files in repo root). Each has a distinctive colored outer shape and a white inner motif. The SVG versions must reproduce the same silhouette, using --color-secondary (Heritage Gold) as the outer fill for all engines unless the PNG shows a different confirmed color. Below each icon's description, the exact color from the PNG is noted.
Voice Engine
Outer shape: rounded square. Inner motif: mic + waveform arc or sound waves. Represents voice input, Sarvam AI STT/TTS pipeline. Nav: Voice (center FAB). Home card label: "Voice". PNG color: Heritage Gold (#C8A96B) dominant.
Finance Engine
Outer shape: rounded square. Inner motif: rupee symbol (₹) or coin stack or upward trend line. Represents accounting, P&L, GST, payments. Nav: Transactions tab (also Finance sub-screen). Home card label: "Finance". PNG color: Olive Green (#5A6B4F).
Customer Engine
Outer shape: rounded square. Inner motif: person outline or two-person group silhouette. Represents customers, suppliers, ledger. Nav: accessed via More tab. Home card label: "Customers". PNG color: Deep Brown (#3B2F2A).
Inventory Engine
Outer shape: rounded square. Inner motif: box/crate outline or shelves. Represents products, stock, warehouse. Nav: Inventory via More tab. Home card label: "Inventory". PNG color: Terracotta (#B45B4A).
Intelligence Engine
Outer shape: rounded square. Inner motif: brain outline or neural-network node dots. Represents the AI analytics, Gemini/GPT reasoning layer. Nav: accessed via AI Core / Reports. Home card label: "Intelligence". PNG color: AI Indigo (#4A3D6B).
Memory Engine
Outer shape: rounded square. Inner motif: database cylinders or bookmark/bookmark-stack. Represents entity memory, vector DB, Firestore. Nav: accessed via More. Home card label: "Memory". PNG color: Heritage Gold variant.
Vision Engine
Outer shape: rounded square. Inner motif: camera lens or eye outline. Represents receipt scanning, image recognition (Google Vision API). Nav: accessed via Camera quick action. Home card label: "Vision". PNG color: Olive Green variant.
Growth Engine
Outer shape: rounded square. Inner motif: upward arrow with bar chart or plant/seedling. Represents predictive analytics, growth recommendations. Nav: Reports > AI Insights. Home card label: "Growth". PNG color: Heritage Gold.
Market Engine
Outer shape: rounded square. Inner motif: storefront or market stall outline or price tag. Represents market intelligence, competitor pricing. Nav: accessed via More. Home card label: "Market". PNG color: Deep Brown variant.
Automation Engine
Outer shape: rounded square. Inner motif: gear/cog or lightning bolt or robot arm. Represents workflow automation, scheduled tasks, triggers. Nav: Settings > Integrations. Home card label: "Automation". PNG color: Terracotta variant.

Color injection rule: All SVG icons use currentColor for stroke and fill. The rendering component sets the color via CSS or a prop — the icon SVG source contains no hardcoded hex. Context colors: nav inactive = --color-text-secondary; nav active = --color-primary; action icons = --color-text-primary; AI icons = --color-ai; status icons use the semantic color matching their state (success/warning/error/info tokens). Engine icons are the sole exception — their outer shape fill is a hardcoded brand hex baked into the SVG since they are decorative brand assets, not functional UI icons.
