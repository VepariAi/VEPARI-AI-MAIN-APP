Spring Presets — P51
All animation in Vepari AI uses spring curves (React Native Reanimated withSpring). Never linear or ease-out tweens for UI interactions. Reduced-motion MUST preserve semantic meaning — never simply remove feedback.
Spring 1 — Snappy (UI controls)
Stiffness / Damping / Mass
400 / 40 / 1
Settle time
~180ms, ~2% overshoot
Used for
Button press scale, chip select, tab indicator slide, checkbox check
Reduced-motion
opacity 0→1 over 100ms, no scale — or instant cut for micro-interactions
Spring 2 — Gentle (cards and sheets)
Stiffness / Damping / Mass
200 / 28 / 1
Settle time
~320ms, ~4% overshoot
Used for
Bottom sheet open/close, card expand, modal entry, screen push/pop
Reduced-motion
opacity 0→1 over 200ms ease-out, no translate — sheet appears in place
Spring 3 — AI Breath (AI Core ring pulse)
Stiffness / Damping / Mass
80 / 12 / 1
Settle time
~1200ms, ~8–10% overshoot (intentional "breathing" feel)
Listening state
scale 1.0→1.06→1.0 (looping), glow shadowBlur 12→28dp
Reduced-motion
Static AI Core. Status pill text → "Listening…" with slow opacity blink (0.6→1.0 at 1.5s ease-in-out)
Spring 4 — Voice Amplitude (waveform bars)
Stiffness / Damping / Mass
200 / 20 / 0.8
Update
30fps driven by RMS amplitude
Reduced-motion
Solid horizontal line, opacity changes (0.4→1.0) on voice activity — no bar movement
Spring 5 — Inertial Scroll
Implementation
React Native ScrollView default (decay 0.998). Do not override.
Rubber-band
iOS native. Android EdgeEffect. No custom implementation.
Reduced-motion
No change needed — scroll inertia is system behavior

RuleApplies toAction
Buttons never truncateAll button labelsFull-width: wrap to max 2 lines. Auto-width: grow or stack. Never ellipsis, never reduce font below 12sp.
List/nav/chip: ellipsis 1 lineList row primary, nav labels, chipsSingle-line truncation with ellipsis. Exception: customer/supplier names on detail screens — 2 lines allowed.
Indic line-heightAll Indic text (even at label sizes)Apply lineHeight = typeScale.*.lineHeightHi even at 11sp. Never fixed pixel height on text containers.
Number formatCurrency, quantities₹ prefix for INR. L/Cr suffix (₹8.4L = ₹8,40,000). Indian number system (2+2+2 commas): 1,00,00,000 not 10,000,000.
Date formatAll datesDD MMM YYYY (27 Aug 2024) for en-IN. Locale-specific for Indic: use Intl.DateTimeFormat('hi-IN') or dayjs locale.
